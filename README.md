# أفراح الزوبير — موقع ممون حفلات ومناسبات في بني ملال

صفحة هبوط (Landing Page) عربية كاملة باتجاه RTL، مبنية بـ **React + Vite + Tailwind CSS**،
مع **لوحة تعديل داخل الموقع** لتغيير كل المحتوى بدون كود.
المشروع مفتوح المصدر برخصة MIT: يمكنك تعديله ونشره كما تشاء.

---

## تعديل المحتوى بدون كود (لوحة التعديل)

1. افتح الموقع وأضف **`#edit`** في آخر الرابط (مثال: `https://example.ma/#edit`)،
   أو اضغط **«تعديل المحتوى»** في أسفل الصفحة.
2. افتح أي قسم من اللوحة وعدّل ما تريد — التغيير يظهر فورًا في الصفحة:
   - كل النصوص والعناوين ونصوص الأزرار وحقول النموذج.
   - أرقام الهاتف وواتساب، العنوان، أوقات العمل، روابط التواصل، الخريطة.
   - إضافة / حذف / ترتيب: الخدمات، الأطباق، الباقات، صور المعرض، الشهادات، المدن، أنواع المناسبات…
   - الصور: اختيار من صور الموقع، **رفع صورة من جهازك**، أو لصق رابط صورة.
   - إظهار أو إخفاء أي قسم كامل.
3. التعديلات تُحفظ تلقائيًا **في متصفحك أنت فقط** (لا يراها الزوار بعد).

### نشر التعديلات لكل الزوار

1. في أسفل اللوحة اضغط **«تنزيل ملف المحتوى»** — ينزل ملف اسمه `content.json`.
2. ارفع هذا الملف إلى الاستضافة **بجانب `index.html`** (استبدل الملف القديم).
3. انتهى: كل الزوار يرون المحتوى الجديد، **دون إعادة بناء الموقع**.

> إن كنت تعمل على الكود: ضع الملف في `public/content.json` ثم `npm run build`.

أزرار أخرى في اللوحة:

- **استيراد ملف**: لمتابعة التعديل على ملف `content.json` سبق تنزيله (مثلًا من جهاز آخر).
- **استرجاع المحتوى الأصلي**: يحذف تعديلاتك المحلية ويعود إلى المحتوى المنشور.

ملاحظات:

- اللوحة لا تحتاج كلمة سر لأنها لا تغيّر شيئًا على الخادم: من يفتحها يغيّر نسخته المحلية فقط.
  النشر الفعلي يتم فقط برفع ملف `content.json` إلى استضافتك.
- لإخفاء رابط «تعديل المحتوى» من أسفل الصفحة: لوحة التعديل ← الفوتر ← أزل علامة الإظهار
  (تبقى اللوحة متاحة عبر `#edit`).
- الصور المرفوعة من الجهاز تُصغَّر تلقائيًا وتُحفظ داخل ملف المحتوى. إن كثرت الصور (أكثر من 15 تقريبًا)
  قد تمتلئ مساحة المتصفح؛ في هذه الحالة استعمل روابط صور أو أضف الصور عبر `images-src/` (انظر «الصور»).
- عنوان الصفحة ووصف SEO والكلمات المفتاحية ليست في اللوحة: تُعدَّل في `index.html`.

### ترتيب أولوية المحتوى

1. تعديلاتك المحفوظة في المتصفح (إن وُجدت) — لك أنت فقط.
2. الملف المنشور `content.json` — لكل الزوار.
3. المحتوى الافتراضي في `src/data/site.ts`.

---

## قبل النشر: معلومات يجب أن تضعها بنفسك

(من لوحة التعديل أو من `src/data/site.ts`)

1. **العنوان** — موضوع حاليًا «بني ملال، المغرب».
2. **أوقات العمل** — أوقات مؤقتة.
3. **الخريطة** — اكتب اسم المحل كما في Google Maps أو العنوان الكامل.
4. **روابط فيسبوك / إنستغرام / تيك توك** — تشير حاليًا إلى الصفحات الرئيسية لهذه المواقع.
5. **محتوى الباقات** — محتوى مقترح، طابقه مع عروضكم.
6. **آراء الزبناء** — شهادات مؤقتة، استبدلها بآراء حقيقية.
7. **الصور** — صور حفلاتكم الحقيقية موجودة (16 صورة في `images-src/`)؛ أضف أو بدّل ما شئت.

وفي `index.html`: بعد ربط الدومين، غيّر `og:image` إلى الرابط الكامل للصورة.

## التشغيل (للمطورين)

تحتاج إلى [Node.js](https://nodejs.org) (الإصدار 20 أو أحدث).

```bash
npm install        # مرة واحدة فقط: تثبيت الحزم
npm run dev        # تشغيل الموقع محليًا مع تحديث فوري عند كل تعديل
npm run build      # بناء النسخة النهائية داخل مجلد dist/
npm run preview    # معاينة النسخة النهائية
```

## النشر

بعد `npm run build` ارفع **مجلد `dist/` كاملًا**
(`index.html` + `content.json` + مجلد `images/` + `og-image.jpg`)
إلى أي استضافة: Netlify، Vercel، GitHub Pages، أو استضافة عادية (cPanel).

## أين أعدّل في الكود؟

| ماذا تريد أن تغيّر؟ | الملف |
| --- | --- |
| المحتوى الافتراضي (كل النصوص والأرقام والقوائم) | `src/data/site.ts` |
| الألوان والخطوط | أعلى الملف `src/index.css` (قسم `@theme`) |
| عنوان الصفحة، وصف SEO، الكلمات المفتاحية، البيانات المنظمة | `index.html` |
| ترتيب الأقسام | `src/App.tsx` |
| شكل قسم معيّن | الملف المقابل له في `src/components/` |
| نص رسالة واتساب المرسلة من النموذج | `src/lib/whatsapp.ts` |
| الأيقونات المتاحة للاختيار | `src/lib/icons.ts` |
| التسميات العربية داخل لوحة التعديل | `src/editor/labels.ts` |

لوحة التعديل تُبنى تلقائيًا من شكل المحتوى في `src/data/site.ts`:
إذا أضفت حقلًا جديدًا هناك يظهر في اللوحة مباشرة (أضف له تسمية عربية في `src/editor/labels.ts`).

## الصور

الصور الأصلية في `images-src/`، والنسخ المضغوطة (WebP بعدة مقاسات) في `public/images/`.
هذه الطريقة تعطي أفضل سرعة تحميل، وهي المفضّلة للصور الدائمة.

**لاستبدال صورة:** ضع صورتك في `images-src/` بنفس الاسم (مثال: `seffa-sugar-cinnamon.jpg`) ثم:

```bash
node scripts/optimize-images.mjs
npm run build
```

**لإضافة صورة جديدة:** ضعها في `images-src/` (مثال: `wedding-1.jpg`) وشغّل السكربت أعلاه؛
ستظهر تلقائيًا في قائمة اختيار الصور داخل لوحة التعديل.

## بنية المشروع

```
index.html                  عنوان الصفحة ووسوم SEO والخطوط
images-src/                 الصور الأصلية
public/content.json         المحتوى المنشور (فارغ {} = المحتوى الافتراضي)
public/images/              الصور المضغوطة (تُولَّد تلقائيًا)
scripts/optimize-images.mjs سكربت ضغط الصور
src/
  App.tsx                   ترتيب الأقسام + فتح لوحة التعديل (#edit)
  index.css                 الألوان، الخطوط، الأزرار، الزخارف، الحركة
  data/site.ts              ← المحتوى الافتراضي كله
  data/images.ts            فهرس الصور (يُولَّد تلقائيًا)
  content/
    ContentProvider.tsx     تحميل المحتوى (متصفح ← content.json ← افتراضي) وحفظه
    utils.ts                دمج المحتوى ودوال مساعدة
  editor/
    ContentEditor.tsx       لوحة التعديل
    labels.ts               تسميات الحقول والأقسام بالعربية
  lib/
    whatsapp.ts             روابط واتساب وبناء رسالة الطلب
    icons.ts                الأيقونات المتاحة
  components/               أقسام الصفحة (Header, Hero, About, Services, Dishes,
                            Packages, WhyUs, Gallery, Testimonials, Areas,
                            QuoteForm, Footer, FloatingActions) + مكوّنات مشتركة
```

## كيف يعمل نموذج الطلب؟

لا يحتاج الموقع إلى خادم. عند الضغط على «إرسال الطلب»:

1. تُفحص الحقول الإلزامية.
2. تُجمع البيانات في رسالة منظمة (`buildQuoteMessage` في `src/lib/whatsapp.ts`).
3. يُرمَّز النص بـ `encodeURIComponent` ويُفتح الرابط `https://wa.me/<الرقم>?text=<الرسالة>`
   على الرقم الذي اختاره الزائر.

- لا يُحمَّل الفيديو إلا عند الضغط على زر التشغيل، فلا يبطّئ الصفحة.
- لتغيير الفيديو: ضع الملف الجديد في `public/video/` وغيّر المسار في `video.src` (يُفضَّل MP4 أقل من 20MB).
  لضغط فيديو كبير: `ffmpeg -i input.mp4 -vf scale=540:960 -c:v libx264 -crf 28 -movflags +faststart -c:a aac -b:a 64k out.mp4`
